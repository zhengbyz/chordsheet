# 阶段 0 已验证的环境（Python 3.12.3 / WSL2 Ubuntu 24.04）
#
# madmom 不能直接 pip install，见下方安装步骤。
#
#   python3 -m venv .venv
#   .venv/bin/python -m pip install -r requirements-stage0.txt
#   .venv/bin/python -m pip install --no-build-isolation \
#       "git+https://github.com/CPJKU/madmom.git@main"
#   .venv/bin/python scripts/stage0_madmom_smoke.py
#
# 三个非显然的坑（都不是 Python 3.12 本身的问题，是生态老化）：
#
# 1. 必须 --no-build-isolation
#    madmom 的 setup.py 顶层 import Cython，但没有 pyproject.toml 声明
#    构建依赖。现代 pip 的构建隔离环境里没有 Cython，直接 build 失败。
#    所以 Cython 要预装在 venv 里，且关掉隔离。
#
# 2. 必须装 git main，不能用 PyPI
#    PyPI 上的 0.16.1 停在 2018 年，processors.py 里是
#    `from collections import MutableSequence`，Python 3.10 已删除该别名。
#    main 分支（0.17.dev0）修了这个，也跟进了 scipy>=1.13，但七年没发版。
#    用 git 装还有个好处：pip 会自动 `git submodule update --init`，
#    madmom 的预训练模型（76 个文件）就在那个 submodule 里。
#
# 3. 必须 setuptools<81
#    madmom/__init__.py 用了 pkg_resources，setuptools 81+ 已移除。
#    这个 pin 是有保质期的技术债，将来 setuptools 彻底清理后需要另想办法
#    （给 madmom 打补丁，或改用 importlib.metadata）。
